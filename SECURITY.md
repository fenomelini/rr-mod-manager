# Segurança

## Como relatar uma vulnerabilidade

Não publique vulnerabilidades ou dados pessoais em uma issue pública. Use a
opção **Report a vulnerability** na aba **Security** deste repositório.

Informe apenas:

- versão do RR Mod Manager e sistema operacional;
- passos para reproduzir usando arquivos sintéticos quando possível;
- impacto observado e necessidade de interação do usuário;
- relatório local revisado, caso ele seja necessário.

Não envie credenciais, URLs privadas, caminhos pessoais, arquivos do jogo,
bancos de dados ou logs completos.

## Itens prioritários

- gravação ou exclusão fora das pastas autorizadas;
- perda de arquivos durante aplicação, restauração ou recuperação;
- escape do isolamento usado para inspecionar arquivos;
- exposição de credenciais ou dados pessoais;
- acesso indevido entre a interface e as funções nativas do aplicativo.
